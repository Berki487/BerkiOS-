# BerkiOS — نظام تشغيل مجاني ومفتوح المصدر

**BerkiOS** نظام تشغيل للكمبيوتر، مبني على **Debian 13 "trixie"**، بسطح مكتب **XFCE** متزيّن ليشبه **macOS** (ثيم WhiteSur + شريط Plank السفلي + خلفية berkiOS). مجاني بالكامل، والتحديثات مجانية كل شهر.

> الشكل شبه ماك، لكنه **ليس** ماك: لا يوجد أي كود من آبل هنا. الثيم WhiteSur مفتوح المصدر (MIT) والتطبيقات بدائل مجانية.

## ما فيه

| الشيء | التفاصيل |
|---|---|
| الأساس | Debian 13 "trixie" (amd64) |
| سطح المكتب | XFCE + ثيم WhiteSur-Dark + أيقونات WhiteSur + مؤشر McMojave |
| الشريط السفلي | Plank (شبه Dock حق ماك) |
| المتصفح | Firefox ESR |
| الأوفيس | LibreOffice (Writer / Calc / Impress) |
| الوسائط | VLC |
| التثبيت | Calamares (مثبّت نظام رسومي) |
| الخلفية | خلفية berkiOS بنفسجية (من تصميمنا) |

## كيف تبني الـ ISO (الخطوات)

### 1. أنشئ المستودع على GitHub
- افتح GitHub → New repository → الاسم مثلاً `BerkiOS` → اختر **Public** (لازم Public عشان GitHub Actions المجاني يبني بدون بطاقة).
- ارفع كل ملفات هذا المجلد إلى المستودع (زي ما رفعت DRAMORA).

### 2. شغّل البناء
- افتح المستودع → تبويب **Actions** → اختر **"Build BerkiOS ISO"** → زر **Run workflow** → Run workflow.
- البناء يشتغل على سيرفرات GitHub (مش على هاتفك، فما يسخّن هاتفك).
- أول بناء ياخذ **20–60 دقيقة** (ينزّل حزم Debian ويبني النظام). انتظر حتى يصير أخضر ✅.

### 3. نزّل الـ ISO
- بعد ما يخلص البناء، افتح نفس التشغيلة (run) في Actions → قسم **Artifacts** → نزّل **berkios-iso**.
- الملف جواه: `live-image-amd64.hybrid.iso` (حجمه تقديرياً 2–4 غيغابايت حسب الحزم).

### 4. جرّبها في جهاز وهمي (VM)
**VirtualBox (الأسهل):**
1. New → الاسم BerkiOS، النوع Linux، الإصدار Debian (64-bit).
2. الرام: 2048 MB على الأقل (4096 أفضل). القرص: 20 GB.
3. Settings → Storage → اربط ملف الـ ISO كقرص ضوئي (Optical Drive).
4. شغّل الجهاز — النظام يشتغل مباشرة من الـ ISO (Live، بدون تثبيت).
5. جرّب سطح المكتب، المتصفح، والتطبيقات. للتثبيت على القرص: افتح **Calamares** من سطح المكتب.

**QEMU (من سطر الأوامر):**
```
qemu-system-x86_64 -m 4096 -cdrom live-image-amd64.hybrid.iso -boot d -enable-kvm
```

## التحديثات الشهرية

المستودع فيه تحديث تلقائي: كل **يوم 1 من الشهر الساعة 03:00 UTC** يشتغل البناء وحده ويبني ISO جديدة من أحدث حزم Debian وأحدث ثيم WhiteSur (الثيم يُنزَّل fresh كل بناء). النسخ الجديدة تظهر في Actions → Artifacts. التحديثات مجانية دائماً.

## حدود النسخة 1.0 (بصراحة)

- **هذه نسخة تجريبية للاختبار (Live ISO)** — جرّبها في VM أولاً، لا تثبّتها على جهازك الرئيسي قبل ما تتأكد أنها شغالة.
- **مثبّت Calamares موجود لكنه غير مختبَر بكثرة** — التثبيت على قرص حقيقي قد يواجه مشاكل؛ أخبرنا بما يحدث وتصلح في النسخة التالية.
- **شكل ماك = ثيم فقط** — النظام أساسه Debian ولينكس، فتطبيقات ماك وويندوز الأصلية لا تعمل عليه مباشرة (بعض برامج ويندوز قد تعمل عبر Wine، لكنها غير مضمونة).
- **البناء يحتاج إنترنت** على سيرفر GitHub (ينزّل حزم Debian والثيم من GitHub).
- **لم يُبنَ الـ ISO بعد** — أول اختبار حقيقي هو تشغيل الـ workflow على GitHub.
